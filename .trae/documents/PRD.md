## 1. 产品概述

Generations As One是一款帮助家庭两代人（甚至三代人）通过AI技术实现更深层次相互理解与沟通的应用。

核心价值：
- **不是数字纪念，而是活的理解**：理解生者之间的理解
- **不是单人沉浸，而是双向互动**：家庭成员之间的相互理解
- **不是性格测试，而是生活沉淀**：通过日常点滴沉淀

4. **理解工坊（Understand）**: 角色互换体验、沟通模拟器、代际桥问答、冲突调解室、家长监护台
5. **专家顾问（Advisor）**: 学习辅导、心理陪伴、家庭理财等专家角色
6. **设置页面**: 隐私设置、账户管理、数据导出

## 3. 核心流程

### 3.1 角色创建流程

用户进入首页 → 点击添加家庭成员 → 填写基本信息（姓名、关系、年龄段） → 一句话描述 → AI智能追问 → 快速标签选择 → 生成初始画像 → 开始对话

```mermaid

    "用户进入首页" --> "点击添加家庭成员"
    "点击添加家庭成员" --> "填写基本信息"
    "填写基本信息" --> "一句话描述"
    "一句话描述" --> "AI智能追问"
    "AI智能追问" --> "快速标签选择"
    "快速标签选择" --> "生成初始画像"
    "生成初始画像" --> "开始对话"
```

### 3.2 点滴记录流程

用户选择家庭成员 → 选择记录方式（语音/文字/照片等） → 输入内容 → AI自动分析处理 → 更新画像 → 显示洞察

```mermaid
flowchart TD
    "用户选择家庭成员" --> "选择记录方式"
    "选择记录方式" --> "输入内容"
    "输入内容" --> "AI自动分析处理"
    "AI自动分析处理" --> "更新画像"
    "更新画像" --> "显示洞察"
```

### 3.3 角色互换流程

用户选择场景/事件 → AI呈现"你的视角" → AI呈现"TA的视角" → 对比分析 → AI给出理解建议

## 4. 用户界面设计

### 4.1 设计风格

**整体美学方向**: 温暖现代 + 情感细腻 + 家庭温馨感

- **主色调**: 
  - 主色：温暖橙色系 `#F97316`（象征家庭温暖）
  - 辅色：柔和蓝绿色 `#0EA5E9`（象征理解与沟通）
  - 背景：柔和米白色 `#FEF7ED` 或淡灰色 `#F5F5F4`
  - 文字：深灰色 `#3F3F46`

- **按钮风格**: 
  - 圆角柔和按钮 `rounded-2xl`
  - 轻微阴影效果 `shadow-sm`
  - hover时有温暖渐变效果

- **字体**:
  - 显示字体：使用温暖感的中文友好字体，如 "思源宋体" 或系统默认
  - 正文字体：清晰易读的无衬线字体
  - 标题：`text-2xl font-semibold`
  - 正文：`text-base`

- **布局风格**:
  - 卡片式布局，温馨的间距
  - 左侧导航栏（桌面端）
  - 底部导航栏（移动端）
  - 家庭成员头像采用圆形呼吸动态效果

- **图标/Emoji风格**:
  - 使用 lucide-react 图标
  - 情感化图标：心形、家庭、对话气泡等
  - 温暖色调的图标

### 4.3 响应式设计

- **桌面优先**: 主要针对桌面端设计，大屏幕体验
- **移动适配**: 
  - 导航栏切换为底部
  - 卡片布局调整为单列
  - 家庭图谱支持手势缩放
- **触摸优化**: 
  - 长按头像快速语音记录
  - 滑动手势切换页面
  - 双指捏合缩放家庭图谱

### 4.4 情感化设计细节

- **头像动态效果**: 轻微呼吸动画（scale pulse）
- **背景色调变化**: 根据用户心情或时间变化
- **纪念日动效**: 重要日期特殊视觉效果
- **成长感**: 新记忆添加时有植物生长般的动效
- **温暖微交互**: hover时的柔和渐变、点击时的轻柔反馈
