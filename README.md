## 四、核心设计原则

1. **隐私优先**：三层可见性（公开/半公开/私密）+ 数据隔离 + 用户专属加密密钥
2. **低门槛**：5步极简创建，多模态随手记，AI主动引导
3. **双向理解**：不是单向记录，而是家庭成员之间的相互理解
4. **坦诚AI**：明确标注"AI模拟视角"，不追求以假乱真，追求视角转换体验
5. **持续成长**：初始画像→持续积累→越来越像，支持家长监护到子女独立的完整生命周期
