## 一、代际桥：理解工坊深度功能

### 1.1 代际问答机

**功能：** 关于对方那代人的"翻译官"
```
问题示例（子女问）：
  "我爸为什么总觉得网上的东西都是骗人的？
  → AI解释：
    基于爸爸成长在信息匮乏的年代，
    他的经验是"眼见为实"，
    对陌生信息的默认态度是怀疑...
    这不是固执，是他那代人的生存智慧。

问题示例（父母问）：
  "我女儿为什么总点外卖，不会自己做饭吗？
  → AI解释：
    基于女儿这代人成长在服务业发达的时代，
    时间比钱更宝贵，
    做饭不是"会不会"，是"值不值"...
    这不是懒，是她那代人的生活方式。
```

### 1.2 时光故事机

**功能：** 让AI家人讲TA那个年代的故事
```
场景：
  用户："爸爸，你小时候过年是什么样的？"
  AI爸爸："啊，过年啊...那时候啊..."
  
  特色：
  • 结合真实记忆+时代背景
  • 不是干巴巴的事实，是有温度的故事
  • 可以随时打断提问
  • 讲完后生成"时代对比"小卡片
```

### 1.3 冲突调解室

**功能：** 家庭冲突后的AI调解
```
流程：
  1. 记录冲突事件（双方都可以记录）
  2. AI分别从双方视角分析
  3. AI生成「冲突全景图」
  4. 提供「修复建议」
  5. 可以模拟「和好对话

冲突全景图示例：
  📍 触发点：要不要换工作
  😔 你的委屈：不被理解、不被支持
  😔 他的委屈：担心你、怕你吃苦
  🎯 共同点：都是为了你好
  💔 错位：表达方式不对
```

## 二、家长角色与未成年人管理

### 2.1 家长角色定义

**家长角色**是家庭中对未成年人有监护责任的成员，拥有特殊的管理权限。

| 属性 | 说明 |
|------|------|
| 角色类型 | 家长（监护人） |
| 权限范围 | 可管理所监护未成年人的账户和数据 |
| 责任期限 | 从创建账户到未成年人独立（年满18岁或自愿独立） |
| 数据归属 | 未成年人独立后，所有数据转移给本人 |

### 2.2 家长监护权限

| 权限 | 说明 |
|------|------|
| 创建账户 | 为未成年子女创建账户 |
| 编辑信息 | 编辑未成年人的公开和半公开信息 |
| 查看记录 | 查看未成年人的所有记录（包括私密） |
| 设置隐私 | 帮助未成年人设置隐私权限 |
| 管理角色 | 管理未成年人养成的角色 |
| 数据转移 | 在未成年人独立时执行数据转移 |

### 2.3 未成年人独立机制

**两个阶段：**

```
阶段一：未成年阶段
├─ 家长是账户的管理者和监护人
├─ 家长可编辑、查看未成年人的所有信息
├─ 未成年人可查看自己的信息，但部分敏感操作需家长确认
└─ 家长记录的关于孩子的点滴 → 家长维护的"我眼中的孩子"视角

阶段二：独立阶段（触发条件：年满18岁或自愿申请独立）
├─ 所有数据自动转移给未成年人本人
├─ 未成年人获得完整的账户控制权
├─ 家长失去监护权限
└─ 家长可继续以"我眼中的孩子"视角养成（但对孩子不可见）
```

### 2.4 家长-未成年人权限矩阵

| 数据类型 | 家长（监护人） | 未成年人 | 其他家庭成员 | AI系统 |
|---------|--------------|---------|------------|--------|
| 未成年人公开数据 | ✓ 可读写 | ✓ 可读 | ✓ 可读 | ✓ 可读 |
| 未成年人半公开数据 | ✓ 可读写 | ✓ 可读 | ✓ 按权限 | ✓ 可读 |
| 未成年人私密数据 | ✓ 可读写 | ✓ 可读 | ✗ 不可访问 | ✓ 可读 |
| 家长记录的关于孩子的点滴 | ✓ 可读写 | ✓ 可读 | ✓ 可读 | ✓ 可读 |
| 家长眼中的孩子（独立后） | ✓ 可读写 | ✗ 不可访问 | ✗ 不可访问 | ✓ 可读（仅家长视角） |
| 孩子独立后的公开数据 | ✓ 可读 | ✓ 可读写 | ✓ 可读 | ✓ 可读 |

### 2.5 数据转移流程

```
触发条件：未成年人年满18岁 或 家长与孩子共同申请独立

流程：
1. 系统检测到独立条件满足
2. 发送通知给家长和未成年人
3. 家长确认转移（或自动确认）
4. 执行数据转移：
   ├─ 所有公开数据 → 转移到未成年人账户
   ├─ 所有半公开数据 → 转移到未成年人账户（权限保留）
   ├─ 所有私密数据 → 转移到未成年人账户（加密密钥转移）
   └─ 家长记录的"我眼中的孩子" → 保留为家长的私人视角（对孩子不可见）
5. 生成转移报告，双方确认
6. 未成年人获得完整控制权，家长转为"观察者"角色
```

### 2.7 隐私设计要点

**关键原则：尊重未成年人的隐私，同时保障家长的监护权**

| 设计要点 | 说明 |
|---------|------|
| 私密数据隔离 | 家长可查看但不可修改未成年人的私密数据 |
| 独立后自动隔离 | 独立后家长视角的数据对孩子完全不可见 |
| 数据转移透明 | 转移时生成详细报告，双方可确认 |
| 过渡缓冲期 | 独立前后有30天缓冲期，可撤回独立申请 |
| 家长情感保留 | 家长可继续以"我眼中的孩子"养成，但严格隔离 |
