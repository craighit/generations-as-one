## 一、AI家庭成员信息录入方案

### 1.1 设计原则

**核心原则：越低门槛，越智能**

| 原则 | 说明 |
|------|------|
| 零输入也能开始 | 不需要长篇大论写人设，3分钟创建角色 |
| 多模态随手记 | 像发朋友圈一样简单，想到什么记什么 |
| AI主动引导 | AI像采访者一样提问，用户只需回答 |
| 越用越精准 | 初始画像→持续积累→越来越像 |
| 隐私可控 | 用户完全掌控哪些信息被记录和使用 |

### 1.2 角色创建流程（5步极简创建）

```
第1步：基本信息（30秒）
  ├─ 姓名/称呼
  ├─ 关系（爸爸/妈妈/爷爷/...）
  ├─ 年龄段
  └─ 上传一张照片（可选，用于生成头像）

第2步：一句话描述（30秒）
  └─ "用一句话描述TA"
      例："我爸是个典型的60后，当过兵，现在退休了，爱下棋"

第3步：AI智能追问（2分钟）
  └─ AI基于一句话自动生成3-5个追问
      例：
      • "他平时说话是什么风格的？"
      • "他最常跟你说的一句话是什么？"
      • "他有什么口头禅吗？"

第4步：快速标签选择（30秒）
  └─ AI生成一组标签，用户快速勾选
      例：[ ] 话不多但心细 [ ] 有点固执但很疼人
          [ ] 爱讲大道理 [ ] 幽默风趣

第5步：生成初始画像（AI自动）
  └─ 3秒生成初始AI角色，可立即开始对话
      （后续通过点滴记录持续优化）
```

### 1.3 点滴记录：6种录入方式

#### 方式一：语音速记（最常用）
**场景：** 刚和家人通完电话，想起什么立刻录下来
```
操作：长按录音→说话→松手→AI自动转写+自动分析
示例：
  用户（语音）："今天我妈又催我结婚了，说隔壁小王都生二胎了..."
  AI处理：
    ✓ 自动转写文字
    ✓ 自动提取关键词：催婚、隔壁小王、二胎
    ✓ 自动分类到「生活事件/沟通记录」
    ✓ 自动更新画像：在"关心子女婚姻"维度+1
    ✓ 自动关联：与3天前的一次类似对话
```

#### 方式二：聊天导入（最智能）
**场景：** 和家人的微信聊天记录，一键导入分析
```
操作：选择聊天记录截图/导出→上传→AI自动分析
AI分析维度：
  • 语言风格分析：用词习惯、语气、口头禅
  • 话题偏好：常聊什么话题
  • 情感倾向：积极/消极/中性比例
  • 沟通模式：谁主动、回复速度、互动深度
  • 性格线索：从对话推断性格特质
```

#### 方式三：事件记录（结构化）
**场景：** 发生了一件重要的家庭事件
```
操作：选择事件类型→填写关键信息→AI补充细节
事件类型模板：
  • 🎂 生日/节日庆祝
  • 😊 开心的时刻
  • 😤 一次争吵/冲突
  • 💡 一次深刻的对话
  • 🎁 收到/送出的礼物
  • 📞 一通重要的电话
  • ...

AI自动补充：
  • 自动关联时间线
  • 自动分析事件对关系的影响
  • 自动生成"记忆摘要"
```

#### 方式四：照片记忆（视觉）
**场景：** 一张老照片或新照片，记录背后的故事
```
操作：上传照片→AI识别内容→用户补充故事
AI能力：
  • 识别人物、场景、年代
  • 自动生成描述
  • 关联到对应家庭成员
  • 从表情分析情绪状态
```

#### 方式五：AI引导式采访（深度）
**场景：** 想深入了解家人，但不知道从何问起
```
操作：选择采访主题→AI扮演采访者→用户以第一人称回答
采访主题库：
  • 童年往事
  • 工作经历
  • 爱情与婚姻
  • 人生最重要的决定
  • 遗憾与欣慰
  • 对子女的期望
  • ...

特色：AI会根据回答动态追问，像真实的访谈一样自然
```

#### 方式六：日常签到（轻量）
**场景：** 每天花1分钟，记录一个小细节
```
操作：打开APP→今日一问→快速回答
今日一问示例：
  • "今天TA做了什么让你印象深刻的事？"
  • "TA今天说的哪句话让你有感触？"
  • "如果用一个词形容今天的TA，是什么？"
  • "今天你们聊了什么话题？"
```

### 1.4 AI画像体系：五层记忆架构

借鉴Kindroid的五层记忆，但针对家庭场景优化：

```
第1层：核心画像（Core Profile）
  ├─ 基本信息：姓名、年龄、关系、职业...
  ├─ 性格特质：大五人格、MBTI、九型人格...
  ├─ 价值观：人生重要排序、信念系统...
  ├─ 语言风格：用词、语气、口头禅、表达习惯...
  └─ 行为模式：决策方式、沟通模式、应对方式...

第2层：事实记忆（Factual Memory）
  ├─ 人生经历：重要事件、时间线、关键节点
  ├─ 人际关系：重要的人、关系故事
  ├─ 喜好厌恶：喜欢什么、讨厌什么
  └─ 知识技能：擅长什么、不懂什么

第3层：情感记忆（Emotional Memory）
  ├─ 情感经历：深刻的情感体验
  ├─ 情绪模式：情绪表达方式、情绪触发点
  ├─ 未竟之事：遗憾、心愿、未完成的
  └─ 情感联结：与每个家人的情感深度

第4层：互动记忆（Interaction Memory）
  ├─ 对话历史：所有的聊天记录
  ├─ 互动模式：和不同人的互动方式
  ├─ 冲突记录：发生过的冲突和解决方式
  └─ 共同记忆：一起经历的事情

第5层：成长记忆（Growth Memory）
  ├─ 变化轨迹：性格、观念随时间的变化
  ├─ 学习成长：新学到的、改变的
  └─ 洞察发现：AI对这个人的深度洞察
```

### 1.5 画像更新机制

```
触发时机：
  • 每次点滴记录后 → 增量更新
  • 每周日晚 → 周度整合
  • 每月末 → 月度深度洞察

更新方式：
  • 不是简单追加，而是"消化吸收
  • AI判断：新信息是补充？修正？还是矛盾？
  • 矛盾信息处理：标记为"认知冲突"，提示用户确认
```

## 二、AI角色扮演交互方案

### 2.1 设计理念

**不是"假装是TA"，而是"理解TA的视角"**

| 传统AI角色 | 我们的AI角色 |
|----------|-----------|
| 追求100%复刻 | 追求"视角转换"的体验 |
| 以假乱真的错觉 | 坦诚的"AI视角模拟 |
| 单向对话 | 双向理解 |
| 娱乐为主 | 成长为主 |

### 2.2 三种角色扮演模式

#### 模式一：日常对话模式（Free Chat）
**定位：** 和AI家人聊天，感受TA的思维方式
```
特点：
  • 像微信聊天一样自然
  • AI会基于画像和记忆回应对话
  • 但会明确标注"AI模拟视角"，避免混淆
  • 对话结束后可生成"对话洞察"

示例：
  用户："如果我辞职去北京工作，你会怎么想？
  AI（模拟爸爸）："（思考中...基于爸爸的性格画像：保守、重视稳定、但也疼孩子"
  "这个...嗯...你也老大不小了，北京压力多大啊..."
  "不过，你真想好了？爸虽然担心你一个人在外头..."
  "但是啊，你真决定了，爸支持。"
  
  对话洞察：
  ✓ 爸爸的第一反应是担心（安全需求>成就需求）
  ✓ 但最终会尊重你的决定（支持型父亲）
  ✓ 建议：可以先跟他聊聊你的规划，让他放心
```

#### 模式二：角色互换模式（Walk in Their Shoes）
**定位：** 站在对方的角度，理解TA为什么这么想
```
操作流程：
  1. 用户选择一个具体场景/事件
  2. AI先呈现"你的视角"（基于用户画像）
  3. AI再呈现"TA的视角"（基于TA的画像）
  4. 对比分析：差异在哪里？为什么？

示例场景：「妈妈又催婚了，你很烦」
  
  你的视角（28岁女儿）：
  • 感受：被催促、被控制、不被理解
  • 想法：我的人生我做主、结婚不是必选项
  • 行为：敷衍、转移话题、有时顶嘴
  
  妈妈的视角（55岁妈妈）：
  • 感受：焦虑、担心、怕你老了孤单
  • 想法：女孩子年纪大了不好找、趁我还能帮你带孩子
  • 行为：反复提、托人介绍、看你烦也得说
  
  AI分析：
  🎯 核心矛盾：你的「自主需求」vs 她的「安全需求」
  💡 理解点：她的催婚本质是爱与担心，不是控制
  🤝 沟通建议：先共情她的担心，再讲你的规划
```

#### 模式三：沟通预演模式（Rehearsal Room）
**定位：** 模拟一次困难对话，提前练习怎么说
```
操作流程：
  1. 用户选择想沟通的话题
  2. 用户先说自己想说的话
  3. AI模拟对方的回应
  4. AI分析沟通效果，给出建议
  5. 可以反复练习不同说法

示例：想跟爸爸说"我不想考公务员"
  
  第1轮：
  用户："爸，我不想考公务员了，我想去互联网公司。"
  AI（模拟爸爸）："什么？！胡闹！公务员多稳定啊！你是不是疯了！"
  
  AI分析：
  ⚠️ 沟通效果：差
  💡 问题：太直接，触发了他的「安全焦虑」
  📝 建议说法：先铺垫，再讲你的理由，最后给他安全感
  
  第2轮（优化后）：
  用户："爸，有件事想跟你商量一下...
        我知道你一直希望我考公务员，稳定..."
  AI（模拟爸爸）："嗯...你说。"
  
  AI分析：
  ✓ 沟通效果：好很多
  💡 亮点：先共情，让他感觉被尊重
  📝 下一步：讲你的规划和理由
```

### 2.3 多角色互动：家庭群聊模式

**场景：** 多个AI家人一起聊天，观察家庭互动模式
```
功能：
  • 可以创建"家庭群聊"，拉入多个AI家人
  • 用户说一句话，看不同人的不同反应
  • AI分析家庭互动模式

示例：
  用户："今年春节去哪过年啊？"
  
  AI爸爸："当然回老家啊，年年不都这样。"（传统型）
  AI妈妈："去海南也行，暖和。"（随遇而安型）
  AI奶奶："回来吧，奶奶想你们了..."（情感型）
  
  家庭互动洞察：
  • 爸爸是决策者（决定型）
  • 妈妈是调和者（随和型）
  • 奶奶是情感中心（联结型）
  • 你是...（基于你的画像）
```

### 2.4 对话中的"诚实"设计

**重要原则：永远不让用户混淆AI和真实**

```
✓ 每次对话开头/结尾都有"AI模拟视角"标识
✓ AI不知道的事情会坦诚说"根据目前的了解，我猜..."
✓ 提供「真实度」指示：基于多少是确定的，多少是推测的
✓ 定期提醒："这是AI模拟的，不代表TA真实的想法"
✓ 鼓励："建议你还是跟TA本人聊聊哦~"
```

## 三、多视角角色与社交网络设计

### 3.1 多视角角色体系

**设计理念：每个人眼中的家人都是独特的**

```
角色：妈妈
├─ 公共版（妈妈自己维护）
│  └─ 妈妈的公开画像、公开记忆
│
├─ 小明眼中的妈妈（小明维护）
│  ├─ 小明记录的关于妈妈的点滴
│  ├─ 小明理解的妈妈的性格
│  ├─ 小明和妈妈的专属记忆
│  └─ 小明对妈妈的情感和看法
│
└─ 爸爸眼中的妈妈（爸爸维护）
   ├─ 爸爸记录的关于妈妈的点滴
   ├─ 爸爸理解的妈妈的性格
   ├─ 爸爸和妈妈的专属记忆
   └─ 爸爸对妈妈的情感和看法
```

**多视角角色的价值：**
- 促进相互理解：通过阅读别人眼中的家人，了解对方的视角
- 保留情感记忆：每个成员都能记录自己独特的观察和感受
- 个性化体验：对话时可以选择不同视角的角色进行互动

### 3.2 多视角权限管理

| 视角类型 | 创建者 | 可见范围 | 可编辑者 |
|---------|-------|---------|---------|
| 公共版 | 角色本人 | 所有家庭成员 | 角色本人 |
| 我眼中的家人 | 家庭成员A | 默认仅本人可见，可选择分享 | 家庭成员A |
| 分享给特定人 | 家庭成员A | 指定的家庭成员 | 家庭成员A |

### 3.3 朋友角色体系

**设计理念：朋友是家庭成员的重要社交延伸**

| 属性 | 说明 |
|------|------|
| 创建者 | 家庭成员个人 |
| 可见范围 | 所有家庭成员可见（公开） |
| 养成者 | 创建者（朋友的添加者） |
| 画像数据 | 由添加者记录和养成 |
| 互动方式 | 可与朋友AI角色对话、了解朋友性格 |

**朋友创建流程：**
```
1. 点击"添加朋友"
2. 填写基本信息（姓名、称呼、关系描述）
3. 上传照片（可选）
4. 一句话描述朋友的性格
5. AI生成初始画像
6. 通过点滴记录持续养成
```

### 3.4 亲戚角色体系

**设计理念：亲戚是家庭关系的扩展网络**

| 属性 | 说明 |
|------|------|
| 创建者 | 任意家庭成员 |
| 可见范围 | 所有家庭成员可见（公开） |
| 养成者 | 所有家庭成员（共同养成） |
| 画像数据 | 家庭成员共同记录和完善 |
| 互动方式 | 可与亲戚AI角色对话、了解亲戚性格 |

**亲戚创建流程：**
```
1. 点击"添加亲戚"
2. 填写基本信息（姓名、称呼、关系）
3. 上传照片（可选）
4. 选择亲戚类型（舅舅、姑姑、表哥、姨妈等）
5. AI生成初始画像
6. 家庭成员共同通过点滴记录养成
```
