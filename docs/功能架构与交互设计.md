## 二、三大核心模块

### 2.1 家庭空间（Home）
**核心价值：建立家庭的数字共同体感**

| 功能 | 描述 |
|------|------|
| 家庭图谱 | 可视化展示家庭成员关系树，每个成员都是一个"活"的节点 |
| 时光走廊 | 家庭共同记忆的时间轴，重要事件、照片、语音记录 |
| 家庭价值观 | 通过AI沉淀家庭共同认同的价值观、原则、家训 |
| 共同目标 | 家庭成员一起设定的目标（如：今年一起去旅行） |

### 2.2 角色养成（Grow）
**核心价值：让AI角色越来越像真实的家人**

| 功能 | 描述 |
|------|------|
| AI画像生成 | 基于心理学模型自动生成多维度人物画像 |
| 点滴记录 | 多种方式记录生活中的言语、行为、事件 |
| 记忆沉淀 | AI自动整理、分类、关联记忆，形成结构化知识 |
| 性格洞察 | 定期生成性格洞察报告，发现行为模式 |
| **私密空间** | 个人私密日记、真实想法、情感树洞（仅自己可见，完善个人画像） |

**设计理念：家庭亲密建立在每个人保有私密空间的基础上**
- 私密功能不是"隐瞒"，而是让用户敢于真实记录
- 私密信息用于完善自己的画像，不影响他人的AI版本
- 没有私密功能，系统会变成"表演舞台"；有了私密功能，系统才是"真正的理解工具"

### 2.3 理解工坊（Understand）
**核心价值：通过互动实现真正的相互理解**

| 功能 | 描述 |
|------|------|
| 角色互换体验 | "如果我是爸爸/妈妈，我会怎么想？" |
| 沟通模拟器 | 模拟与家人对话，预演沟通场景 |
| 代际桥问答 | 关于对方年代、经历、价值观的智能问答 |
| 冲突调解室 | AI扮演中立调解者，分析冲突并提供建议 |
| **家长监护台** | 家长可管理未成年人账户，编辑其信息；未成年人独立时转移所有数据，家长可继续以"我眼中的孩子"视角养成 → 详见 [理解工坊与家长管理.md](理解工坊与家长管理.md) |

## 三、交互设计亮点

### 3.1 首页设计：家庭客厅

```
┌─────────────────────────────────┐
│  早上好，小明 👋               │
│  今天是和爸爸的第 128 天         │
├─────────────────────────────────┤
│                                 │
│   [爸爸头像]  [妈妈头像]  [奶奶头像]│
│     爸       妈       奶        │
│     92%像     87%像    76%像    │
│                                 │
│  💭 今日一问                      │
│  "今天妈妈做了什么让你印象深刻的事？" │
│  [点击回答]                        │
│                                 │
├─────────────────────────────────┤
│  📝 点滴记录  🎭 角色互换  💬 对话 │
│  🏠 家庭空间  🌉 代际桥  📊 洞察 │
└─────────────────────────────────┘
```

### 3.2 核心交互手势

| 手势 | 功能 |
|------|------|
| 长按头像 | 快速语音记录点滴 |
| 点击头像 | 进入对话 |
| 双指捏合 | 缩小看家庭图谱 |
| 左滑 | 查看记忆 |
| 右滑 | 记录新点滴 |

### 3.3 情感化设计

- **角色头像会"呼吸"，有轻微的动态
- 不同心情有不同的背景色调
- 重要纪念日有特殊动效
- 新记忆有"成长感"（像植物生长一样）
