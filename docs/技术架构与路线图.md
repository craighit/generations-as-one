# Generations As One - 技术架构与路线图

**所属项目**：Generations As One
**文档版本**：v1.3
**最后更新**：2026-06-29

---

## 一、技术栈建议

| 层级 | 技术选型建议 |
|------|-----------|
| 前端 | React Native / Flutter（跨端） |
| 后端 | Node.js / Go |
| 大模型 | 国内：通义千问/文心一言/DeepSeek（多模型适配） |
| 向量数据库 | Milvus / Pinecone |
| 语音合成 | 微软TTS / 阿里云语音 |
| 图像理解 | 通义万相 / 百度文心一格 |

---

## 二、MVP版本功能优先级

### Phase 1（核心体验）：

- 家庭成员创建（5步极简创建）
- 语音/文字点滴记录
- 基础AI对话
- 简单画像展示

### Phase 2（理解功能）：

- 角色互换模式
- 代际桥问答
- 聊天记录导入
- 周度洞察报告

### Phase 3（深度功能）：

- 沟通预演模式
- 家庭群聊
- 冲突调解室
- 家庭价值观沉淀

### Phase 4（扩展功能）：

- 多视角角色体系
- 朋友与亲戚角色
- 家长监护功能
- 专家顾问模块
